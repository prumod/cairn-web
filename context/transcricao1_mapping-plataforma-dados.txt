- `Diário da República`
  - Agregado: `Concurso`
    - Anúncio de concurso público → entidade/VO `AnuncioConcurso`
    - Concurso aberto/ativo → `EstadoConcurso.Aberto`
    - Descrição do concurso → `DescricaoConcurso`
    - Descrição do trabalho a executar → `DescricaoTrabalho`
    - Entidade que publica/promove o procedimento → `EntidadeAdjudicanteRef`
    - Ficheiros associados ao anúncio → entidade `DocumentoConcurso`
  - É a principal fonte usada pelo Derlan para descobrir novos concursos; é consultada diariamente. transcricao1_gestao_obras transcricao1_gestao_obras transcricao1_gestao_obras

- `Portal BASE`
  - Agregado: `Concurso`
    - Resultado da adjudicação → VO `ResultadoAdjudicacao`
      - Empresa vencedora → `ResultadoAdjudicacao.adjudicatario : EmpresaRef`
      - Valor da adjudicação → `ResultadoAdjudicacao.valor : Dinheiro`
      - Origem/entidade do concurso → `ResultadoAdjudicacao.entidadeAdjudicante : EntidadeAdjudicanteRef`
    - Concurso já adjudicado → `EstadoConcurso.Adjudicado`
  - O Portal BASE é usado sobretudo depois da adjudicação e apenas ocasionalmente pelo Derlan. A entrevista **não confirma** que estes dados sejam automaticamente ou manualmente copiados do Portal BASE para o SAGE/Excel. transcricao1_gestao_obras transcricao1_gestao_obras

- `Plataforma de submissão de propostas`
  - Agregado: `Concurso`
    - Convite para participar → entidade `Convite`
      - Entidade que convidou → `Convite.entidade : EntidadeAdjudicanteRef`
      - Estado da decisão → `EstadoConvite` (`Pendente`, `Aceite`, `Recusado`)
  - Agregado: `Proposta`
    - Nome/identificação da obra → `ReferenciaObra`
    - Descrição do concurso → `DescricaoConcurso`
    - Valor proposto → `ValorProposto : Dinheiro`
    - Documentos exigidos → coleção de entidades `DocumentoProposta`
    - Documentos do responsável da empresa → `DocumentoProposta`
    - Mapa de medições → entidade/VO `MapaMedicoes`
    - Cronograma financeiro → entidade/VO `CronogramaFinanceiro`
      - Período/mês → `Periodo`
      - Percentagem prevista de execução → `PercentagemExecucao`
      - Valor previsto → `Dinheiro`
    - Submissão da proposta → `EstadoProposta.Submetida`
  - A plataforma é o local onde são obtidos documentos para concorrer e onde a proposta é validada/enviada. transcricao1_gestao_obras
  - Nos concursos por convite, a decisão de participar e a interação com o procedimento também são feitas nesta plataforma. transcricao1_gestao_obras

- `SAGE`
  - Agregado: `Obra`
    - Registo da obra → `Obra`
    - Valor pelo qual a empresa ganhou a obra → `ValorAdjudicado : Dinheiro`
    - Outros dados administrativos da obra → `DadosAdministrativosObra`
      - A entrevista não identifica estes campos individualmente.
  - Agregado/entidade: `Funcionario`
    - Registo do funcionário → `Funcionario`
    - Dados administrativos do funcionário → `DadosAdministrativosFuncionario`
      - Os campos concretos não foram enumerados na entrevista.
  - Contexto: `Faturacao`
    - O SAGE também trata faturação, mas a entrevista não fornece detalhe suficiente para definir entidades ou Value Objects desse contexto.
  - A versão mais recente do SAGE é usada para registar obras e guardar, por exemplo, o valor pelo qual a empresa ganhou a obra. transcricao1_gestao_obras

- `E-mail`
  - Agregado: `Concurso`
    - Aviso de novo convite → `NotificacaoConvite`
      - Referência ao concurso/convite → `ConviteId`
      - O e-mail é apenas uma notificação; a ação é realizada na plataforma de submissão.
    - Eventual resposta de recusa → `RespostaConvite`
      - Estado → `EstadoConvite.Recusado`
      - Motivo/texto → `MotivoRecusa`
  - Agregado: `ProcessoCotacao`
    - Pedido de cotação enviado a fornecedor → entidade `PedidoCotacao`
      - Fornecedor → `FornecedorId`
      - Material/serviço pretendido → `ItemPretendido`
    - Cotação recebida → entidade `Cotacao`
      - Fornecedor → `FornecedorId`
      - Preço → `Preco : Dinheiro`
      - Prazo de validade → `ValidadeCotacao`
  - Os pedidos de preços são feitos por e-mail e telefone; as cotações podem ter validades de 48 horas, alguns dias, semanas ou meses. transcricao1_gestao_obras transcricao1_gestao_obras
