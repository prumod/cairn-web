# Cairn documentation

- [Architecture](../ARCHITECTURE.md) describes the full-stack TanStack Start application, its server/client boundaries, and deployment constraints.
- [Testing](../TESTING.md) describes test boundaries and what empty suites do—and do not—establish.
- [Coding standards](../CODING_STANDARDS.md) covers code contracts and comments; native tool configuration owns mechanical style.
- [Product documentation](product/README.md) is written for people to understand shared product scope, requirements, research, and source material. Agents can consult it when relevant; that does not make it agent-only.
- How-to guides for common development tasks, with agents in T3 or manually: [work with agents in T3](how-to/trabalhar-com-agentes-no-t3.md), [develop a feature](how-to/desenvolver-uma-funcionalidade.md), [modify a feature](how-to/modificar-uma-funcionalidade.md), [fix a bug](how-to/corrigir-um-bug.md), [refactor code](how-to/refatorar-codigo.md), and [create a design](how-to/criar-um-design.md). [Processes and skills](reference/processos-e-skills.md) lists the processes and skills to choose from.
- [Agent guidance](agents/) is written specifically for coding agents. `AGENTS.md` links to these guides when their conditions apply.
- The repository [README](../README.md) covers contributor setup and workflow. The root [GLOSSARY](../GLOSSARY.md) records shared product terminology.
